🧠 NonlinearModel Complete Guide

Understanding a 2→32→32→1 Neural Network for Signal Prediction

📐The Model Structure

The NonlinearModel is a simple feedforward neural network with the following architecture:

import torch
import torch.nn as nn


class NonlinearModel(nn.Module):
    def __init__(self):
        super().__init__()
        self.fc1 = nn.Linear(2, 32)    # Input: 2 features → 32 neurons
        self.fc2 = nn.Linear(32, 32)   # Hidden: 32 neurons → 32 neurons
        self.fc3 = nn.Linear(32, 1)    # Output: 32 neurons → 1 prediction

    def forward(self, x):
        x = torch.relu(self.fc1(x))    # First layer + ReLU activation
        x = torch.relu(self.fc2(x))    # Second layer + ReLU activation
        return self.fc3(x)              # Output layer (no activation)

⭐ Total Parameters: 1,185 — All of these get trained to minimize prediction error.

⚡Understanding ReLU Activation

ReLU (Rectified Linear Unit) is an activation function that introduces nonlinearity. Without it, stacking layers would just be multiple linear transformations, which collapse to a single linear operation.

What ReLU Does

Formula: ReLU(x) = max(0, x)

  • If input ≤ 0: output is 0 (neuron "switches off")
  • If input > 0: output is the input unchanged (neuron "fires")

Why ReLU Matters

🎯 Enables Learning

The kink at zero breaks linearity. This allows the network to learn curved, nonlinear relationships in data — essential for signal reconstruction.

⚡ Sparse Activation

Roughly half the neurons output zero. This sparsity is efficient and forces the network to learn selective, meaningful features.

🎓One Training Cycle (Simple View)

Training teaches the model to predict accurately. Each cycle involves 5 simple steps:

1

Get a sample

Input: 2D signal point (e.g., [sin(t), cos(t)]) | Target: what output should be

2

Predict (forward pass)

Push data through model: input → FC1 → ReLU → FC2 → ReLU → FC3 → prediction

3

Measure error

Loss = (prediction - target)² | Shows how wrong the model is

4

Backpropagation (find fault)

Model figures out: "which weights caused this error?" using chain rule

5

Update weights

Nudge each weight in the right direction: w_new = w - learning_rate × gradient

🚀Inference: Making Predictions

Once the model is trained, inference is just the forward pass — no training, no weight updates. The learned weights stay frozen.

One Inference Cycle (5 Steps)

What Happens

Data flows left to right. Each layer transforms the data:

  • Input (2D): Raw signal point
  • FC1 (32D): Learned features from the signal
  • ReLU (32D): Some features activate, others zero out
  • FC2 (32D): Refined features, higher-order patterns
  • ReLU (32D): Sparsity again
  • FC3 (1D): Final prediction
✅ No weight updates happen during inference. The weights learned during training are frozen. Inference is purely computational — push data through, get answer.

⚙️Training vs Inference

🎓 Training

  • Goal: Learn weights
  • Steps: Forward → Loss → Backward → Update
  • Frequency: Thousands of iterations
  • Weights: Change with each step
  • Gradients: Computed for every parameter
  • Speed: Slower (backprop is expensive)
  • Data: Training set (with known targets)

🚀 Inference

  • Goal: Make predictions
  • Steps: Forward pass only
  • Frequency: Once per prediction
  • Weights: Frozen (never change)
  • Gradients: Not computed
  • Speed: Fast (just matrix multiplications)
  • Data: Test set (unknown targets)

📌Key Takeaways

1️⃣ Architecture Pattern: Expand → Refine → Collapse

2D → 32D (FC1): Expand input to learn diverse features | 32D → 32D (FC2): Refine features, learn interactions | 32D → 1D (FC3): Collapse to final prediction

2️⃣ ReLU Creates Nonlinearity

Without ReLU, stacked linear layers collapse to a single linear transformation. ReLU's kink at zero breaks linearity, enabling the network to learn curved relationships.

3️⃣ Training: Learn → Predict → Measure → Fix

Thousands of cycles: predict (often wrong) → measure error → backprop to find which weights caused the error → nudge weights in better direction → error decreases

4️⃣ Inference: Frozen Weights → Fast Predictions

Once trained, weights never change. Inference is just forward pass: input data → matrix multiplications → output prediction. No gradients, no training overhead.

5️⃣ Parameters & Learning

1,185 weights all work together. Each learns a small piece of "how to predict this signal." After thousands of training samples, they collectively solve the prediction task.
